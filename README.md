# simple_crm

Простая CRM с канбан-доской задач. Backend: Python + FastAPI + SQLite. Frontend: Vue 3 + Vite.

## Возможности

- 5 рабочих аккаунтов (создаются автоматически при первом запуске).
- Канбан-доска: К выполнению / В работе / На проверке / Готово.
- У задачи один постановщик, несколько исполнителей, несколько наблюдателей.
- Задачу видят только постановщик, исполнители и наблюдатели.
- Менять статус задачи может только постановщик или исполнитель.
- Любая смена статуса требует комментарий (сохраняется в истории задачи).
- Задачу можно вернуть в статус "В работе" из любого статуса.

## Запуск backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

При первом запуске создаются аккаунты `user1`..`user5` с паролями `password1`..`password5`.

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173
